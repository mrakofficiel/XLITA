XLITA — PREMIUM SCROLL 3D EXPERIENCE

This is an original XLITA concept website inspired by the premium feel of modern automotive product pages. It is not a copy of Ferrari assets or source code.

GITHUB PAGES
1. Extract this ZIP.
2. Upload index.html and the assets folder directly into the ROOT of your GitHub repository.
3. Confirm: assets/xlita.glb exists.
4. GitHub: Settings > Pages > Deploy from a branch > main > /(root) > Save.

LOCAL CHROME TEST
Run in this folder:
python -m http.server 8000
Then open http://localhost:8000

FEATURES
- Large visible 3D XLITA model from the first screen
- White premium studio presentation
- Scroll-driven 360+ degree cinematic orbit
- Manual drag rotation
- Door reveal
- Cockpit close-up
- Engine/hood reveal
- Rear aero / active wing motion
- White, silver, red, blue, green and black colour options
- High-DPI rendering up to 3x device pixel ratio

NOTE
Browser output cannot exceed the user's actual display resolution. The site is optimized for high-resolution displays, but a 10K monitor is required to physically display 10K pixels.
